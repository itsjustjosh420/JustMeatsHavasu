# Just Meats — site

This is a small Next.js (app router) + Tailwind site.

Local development:
1. Install dependencies:
   npm install

2. Run dev server:
   npm run dev
   Open http://localhost:3000

Build & start:
npm run build
npm run start

Deployment:
- Recommended: deploy to Vercel (just connect the repo and Vercel will build & deploy).
- GitHub Pages is not suitable for Next.js app-router apps; if you want Pages, we can convert to a static site or use an export workflow.
